# Python Practice Exercises

Small Python programs exploring object-oriented programming, file handling and everyday application logic.

## Exercises

| Folder | Examples |
| --- | --- |
| `challeges-1/` | Weather requests, file handling, food delivery, sales tracking and recommendations |
| `challeges-2/` | Library, restaurant, student-management and to-do examples |
| `challeges-4/` | Flight-booking exercise |

## Run

Use Python 3 and run an individual script, for example:

```bash
python 'challeges-2/Todolist.py'
```

Read each script's imports and input prompts first. Some exercises require additional packages, an external service or local data. This repository is a learning collection rather than one installable application. Use dummy accounts and data.
